# goit-pycore-hw-07

Домашнє завдання до теми 10: розширене ООП. Бот-помічник із попередніх робіт тепер зберігає контакти в адресній книзі на класах і вміє працювати з днями народження.

## Структура

- `address_book.py` — класи `Field`, `Name`, `Phone`, `Birthday`, `Record` та `AddressBook` з методом `get_upcoming_birthdays`
- `bot.py` — консольний бот: розбір команд, обробники з декоратором `input_error`, функція `main`

## Запуск

Сторонні бібліотеки не потрібні, достатньо Python 3.

```
python bot.py
```

## Команди

- `add [ім'я] [телефон]` — додати контакт або ще один номер до наявного
- `change [ім'я] [старий телефон] [новий телефон]` — замінити номер
- `phone [ім'я]` — показати телефони контакту
- `all` — показати всі контакти
- `add-birthday [ім'я] [DD.MM.YYYY]` — додати день народження
- `show-birthday [ім'я]` — показати день народження
- `birthdays` — кого привітати протягом наступних 7 днів
- `hello` — привітання від бота
- `close` або `exit` — вийти

Телефон має складатися рівно з 10 цифр, дата народження вводиться у форматі `DD.MM.YYYY`. Якщо день народження випадає на вихідний, привітання переноситься на понеділок.
